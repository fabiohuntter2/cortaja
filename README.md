# CortaJá

Criado por **Fabio Huntter**.

Editor de vídeo para celular que roda no navegador: corte limpo (tira pausas e repetições), legendas automáticas palavra por palavra, zoom dinâmico, textos, transições e exportação rápida em MP4. O vídeo é processado no próprio aparelho.

Abra no Chrome (Android) ou Safari (iPhone) e use "Adicionar à tela inicial" para instalar.
